## 2. Distinction Between Weather Extremes and Drought Classes

A fundamental failure in earlier drafts was conflating acute weather with agricultural drought. The physical differences are defined below:

```
+-----------------------------------------------------------------------------------------+
|                               ATMOSPHERIC & HYDROLOGICAL CONTINUUM                      |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|  [ ACUTE HEAT DESICCATION ]   [ METEOROLOGICAL DROUGHT ]   [ AGRICULTURAL DROUGHT ]     |
|  * Timescale: Hours to Days   * Timescale: Months          * Timescale: Weeks to Months |
|  * Driver: High Tmax & Low RH * Driver: Rain Deficit       * Driver: Root-Zone Moisture |
|  * Impact: Midday Wilting,    * Impact: River/Aquifer      * Impact: Prolonged Crop     |
|    Spikelet Sterility           Depletion                    Stunting & Failure         |
|  * Member 2 Coverage: YES     * Member 2 Coverage: NO      * Member 2 Coverage: NO      |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

1. **Acute Atmospheric Desiccation (Member 2 Scope):**
   * Occurs when air temperature exceeds $35^\circ\text{C}$ and relative humidity drops below $50\%$.
   * Causes extreme Vapour Pressure Deficit ($\text{VPD} > 3.0\text{ kPa}$), forcing rapid transpiration that exceeds root hydraulic uptake capacity.
   * **This is what Member 2's dataset and model successfully detect.**
2. **Agricultural Drought (Beyond Member 2 Scope):**
   * Occurs when root-zone soil water is depleted below the permanent wilting point ($D_r > \text{RAW}$).
   * Requires knowledge of soil water holding capacity (TAW), root depth ($Z_r$), irrigation applications, and cumulative daily water balances ($P - ET_c$).
   * **Member 2 does NOT have soil moisture, soil texture, or irrigation data, and cannot claim agricultural drought prediction.**

## 3. Spatial Resolution & Geographic Representation

### 3.1 Point Query vs. Field-Level Sensors
* The data in `cleaned_weather_dataset.csv` was queried at coordinates `(24.3636°N, 88.6241°E)`, corresponding to the **Rajshahi Meteorological Station** (BMD Station 41859).
* The centroid of **Godagari Upazila** is `(24.469°N, 88.330°E)`, located approximately **34.8 km to the west-north-west**.
* While regional synoptic weather patterns (pre-monsoon heatwaves and seasonal monsoon onset) are broadly homogeneous across the Greater Rajshahi district, localized convective rainstorms, village-level microclimates, and irrigation canal micro-humidity vary across this distance.
* **Prohibited Claim:** Never claim that this dataset represents direct in-situ sensor measurements from individual farm fields in Godagari.

### 3.2 NASA POWER Model Grid Scale
* NASA POWER temperature, humidity, wind, and precipitation originate from the **GMAO MERRA-2 assimilation model** on a native $0.5^\circ \times 0.625^\circ$ grid (approximately $50\text{ km} \times 60\text{ km}$ per grid cell).
* Solar radiation originates from satellite radiometers on a $1.0^\circ \times 1.0^\circ$ grid (approximately $100\text{ km} \times 100\text{ km}$).
* Consequently, NASA POWER values represent grid-box spatial averages, not micro-climate field measurements.

## 4. Machine Learning Scope & Prohibited Claims

### 4.1 What the Machine Learning Model Actually Does
* The XGBoost classifier (`drought_heat_model.json`) was trained on a synthetic ground truth generated by:
  $$\text{Target} = (t_{\max} \ge 35.0) \land (\text{humidity} \le 50.0) \land (\text{rainfall} \le 1.0)$$
* The model reconstructs this rule with 99.7% accuracy.
* **It is a rule-reconstruction algorithm, not an empirical forecasting model trained on ground-truth agricultural yield loss.**
